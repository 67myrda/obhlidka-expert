# ObhlídkaEXPERT

Odlehčená verze appky ObhlídkaPROFI pro kolegy (Domoveo): zápis stavu oken při obhlídce, výpočet metrů těsnění, souhrn NUTNÉ / DOPORUČENÉ / NA ZVÁŽENÍ a podklad pro přepis do aplikace Domoveo.

- Funguje offline (service worker), lze přidat na plochu telefonu/tabletu (iPhone: Safari → Sdílet → Přidat na plochu).
- Data zůstávají jen v zařízení (localStorage), žádný server. Po obhlídce pošlete zálohu a přepište výsledek do Domovea.
- 🛟 Postup prohlídky: bodový přehled fází 0–9 + Slovník okenních pojmů.
- Aplikace: https://expert.iqapps.cz/
